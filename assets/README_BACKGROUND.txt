========================================================================
         CUSTOM MAIN MENU BACKGROUND INSTRUCTIONS
========================================================================

To set a custom background image for the start menu:

1. Save any image (PNG or JPG format) into this `assets/` directory
   or directly into the main game root folder.

2. Name your image file as one of the following:
   - menu_bg.png
   - menu_bg.jpg
   - background.png
   - background.jpg

3. Launch or restart the game! The game will automatically detect and
   load your background image on the main menu.
